# TrailMem Code of Conduct

## Our commitment

We want TrailMem to be a welcoming, professional project for everyone who
uses or contributes to it. Participation in project spaces requires respectful
and constructive behaviour, regardless of experience, identity, or background.

## Expected behaviour

- Be considerate in issues, pull requests, discussions, and other project
  spaces.
- Give technical feedback about the work, not the person.
- Assume good intent, ask clarifying questions, and accept reasonable feedback.
- Respect privacy and do not publish someone else's personal information.

## Unacceptable behaviour

Harassment, discrimination, threats, personal attacks, sexualised language or
imagery, deliberate disruption, and sharing private information without
permission are not acceptable.

## Scope and enforcement

This policy applies in TrailMem's GitHub repository, discussions, issue
tracker, pull requests, and project-related communications. Maintainers may
remove content, reject contributions, or restrict participation when behaviour
violates this policy. Report concerns privately to the maintainer using the
contact details in the project's package metadata; reports will be handled as
confidentially as practical.
